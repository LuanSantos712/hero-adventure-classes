# Hero Adventure

## Technical Overview

This project was developed in Java as part of a hands-on programming logic challenge on DIO. It simulates a simple adventure game by representing heroes with different attributes and attack abilities based on their character types.

The implementation applies fundamental programming concepts, including variables, data types, conditional statements, loops, methods, classes, and objects. It uses a constructor to initialize each hero's attributes and conditional logic to determine the appropriate attack based on the hero's type.

## Key Features

- Defines a `Heroi` class with name, age, and character type attributes.
- Creates multiple hero objects with different characteristics.
- Implements an `atacar()` method that assigns an attack based on the hero's type.
- Uses conditional statements to determine the appropriate attack.
- Stores hero objects in an array and iterates through them using a `for` loop.
- Displays the corresponding attack message in the console.

## Technologies and Concepts

- **Language:** Java
- **Object-Oriented Programming:** Classes, objects, attributes, and constructors
- **Control Flow:** Conditional statements (`if`, `else if`, and `else`) and `for` loops
- **Methods:** Defining and executing the `atacar()` method
- **Arrays:** Storing and iterating through multiple hero objects
- **String Handling:** Comparing strings with `equalsIgnoreCase()` and concatenating output messages
- **Console Output:** Displaying results with `System.out.println()`

## Future Improvements

- Encapsulate class attributes using `private` access modifiers and provide appropriate getters and setters.
- Validate character types to prevent unsupported values.
- Allow users to create heroes and select character types through console input.
- Expand the attack system with additional abilities and character types.
- Introduce inheritance and polymorphism to create a more flexible object-oriented design.

## Learning Objectives

This project reinforces the fundamentals of Java and introduces practical object-oriented programming concepts. It provides hands-on experience with classes, objects, constructors, methods, conditional logic, and arrays while demonstrating how to organize code into reusable components.
